# 描画プログラム

キーマップ可視化 デザインルール（`spec.md`）の参照実装です。中間データ（JSON）とテーマ（JSON）から、仕様どおりのSVGを描きます。正本は仕様で、仕様とこのプログラムが食い違う場合はプログラムを直します。このプログラムを実行できる環境では、キーマップビジュアルは必ずこのプログラムで描きます（第10.10節）。

## 使い方

Node.js（18以上）だけで動きます。インストールは要りません。

```
node renderer/render.mjs renderer/examples/torabo-tsuki-lp-xs-windows.json -o keymap.svg
```

| オプション | 内容 |
|---|---|
| `--theme <名前\|パス>` | テーマ。名前なら `themes/<名前>.json` を使う。省略すると既定テーマ（`clay`） |
| `-o <パス>` | 出力先。省略すると標準出力に書く。キーマップビジュアルの組では出力先ディレクトリ |

OS別のキーマップビジュアルなど、組になるキーマップビジュアルは、中間データをまとめて渡します。表示スロットの割り当てとキーの大きさを組全体で揃えて、各キーマップビジュアルを `<出力先>/<中間データの名前>.svg` に書きます（仕様 第10.10節）。

```
node renderer/render.mjs keymap-windows.json keymap-macos.json -o out
```

## 流れ

1. キーマップと設定ファイルを解析し、入力項目を質問で確定させる（仕様 第10.0節）。
2. キーマップビジュアルの内容を中間データにまとめる。形式は `schema.json` を正本とする。例は `examples/` を参照。
3. このプログラムで SVG を描く。
4. 描いたキーマップビジュアルを、仕様 第10.8節の項目で確認する。

## ファイル

| パス | 内容 |
|---|---|
| `render.mjs` | 描画プログラム本体 |
| `schema.json` | 中間データの JSON Schema |
| `examples/torabo-tsuki-lp-xs-windows.json` | 中間データの例（torabo-tsuki LP XS、Windows） |
| `../themes/*.json` | テーマ |
| `../icons/*.svg` | 操作アイコン |

## 中間データの書き方

項目と書き方は `schema.json` と仕様 第10.10節にあります。次のものは、文字列のほかにオブジェクトでも書けます。

| 書くもの | 書き方 | 仕様 |
|---|---|---|
| 意味を確かめていない仮の名前 | `base`・`hold`・セル・`taps`・`combos` に `"tentative": true`。描画プログラムが「?」と注釈を付ける | 第9.4節 |
| 追加レイヤーにいる間だけ使えるレイヤー切り替え | セルに `"switch": { "layer": "adj", "via": "hold" }`。Base へ戻るときは `"layer": "base"` | 第4.5節 |
| 直前のキーで出力が変わるキーの対応表 | `"note": { "text": "…", "table": [["A", "o"], [["C", "D"], "y"]] }` | 第8.2節 |

## 中間データの検証

プログラムは、描くのに必要な項目（キー・レイヤー・Comboの参照など）だけを確認します。`schema.json` での厳密な検証は、JSON Schema に対応したツールで行ってください。

```
npx ajv-cli validate --spec=draft2020 -s renderer/schema.json -d renderer/examples/torabo-tsuki-lp-xs-windows.json
```

## できないこと

- 短縮表記は作りません。隣接Comboのラベル・セルの文字・基本入力・操作表示（Hold・Tap Dance・追加レイヤー内の Hold）が収まらないときは、文字縮小（75%まで）→ キー拡大（最大1.5倍）→ 中間データの短縮表記（`short`）→ 50%までの縮小（キー拡大を上限まで使ったうえで、短縮表記を先に縮める）の順に自動で試し（仕様 第10.10節）、それでも収まらないComboを識別子方式にします。セルの文字と基本入力が収まらない場合は50%で描き、警告を出します。短縮表記を使わせたい場合は、中間データの `short` に書いてください（セルは `{ "text": "…", "short": "…" }`、追加レイヤー内の Hold は `"hold": { "text": "…", "short": "…" }`）。
- 分割型かどうかは推定しません。中間データの `meta.split` に `true`（分割型）か `false`（一体型）を書いてください（仕様 第10.0節）。
- SVGはフォントを Google Fonts から読み込みます。オフラインのときや、画像（`<img>`）として埋め込んだときは、代わりのフォントで表示されます。
- PNGに変換するときは、テーマのフォントを使える環境で行ってください（仕様 第10.9節）。使えない場合はPNGを作らず、SVGだけを渡します。
